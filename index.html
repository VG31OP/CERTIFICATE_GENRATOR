SMTP Configuration
Step-by-Step Setup Guide
Gmail Configuration (Requires 16-character App Password)
  1. Open your Google Account Security settings (myaccount.google.com/security).
  2. Under "How you sign in to Google", ensure 2-Step Verification is enabled.
  3. Search for "App Passwords" or navigate to myaccount.google.com/apppasswords.
  4. Generate a new App Password named Certificate Studio.
  5. Copy the generated 16-letter password (e.g. abcd efgh ijkl mnop).
  6. Enter your full Gmail in Username and paste the 16-character code into the Password field below.
  7. Host: smtp.gmail.com | Port: 587, then click Test Connection.
Crucial: Standard Gmail passwords will fail with "Bad Credentials". You must generate an App Password.
Outlook / Office 365 Configuration
  1. Host: smtp.office365.com | Port: 587.
  2. Enter your Microsoft account email in Username.
  3. Enter your account password (or App Password if MFA is enabled on your organization).
  4. Click Test Connection.
Yahoo Mail Configuration
  1. Go to your Yahoo Account Security page and click "Generate app password".
  2. Create an app password for Certificate Studio.
  3. Host: smtp.mail.yahoo.com | Port: 587 | Username: your Yahoo email.
  4. Paste the generated Yahoo App Password into the Password field.
Custom / Enterprise SMTP Server
  1. Enter your SMTP server hostname (e.g., mail.yourcompany.com or smtp.sendgrid.net).
  2. Use Port 587 (STARTTLS) or 465 (SSL).
  3. Enter your SMTP authentication username and secret key / password.
  4. Click Test Connection to verify authorization.
